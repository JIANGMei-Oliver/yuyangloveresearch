# Yuyang Love Research

A static academic portfolio for Yuyang Jiang, designed for GitHub Pages.

## Preview locally

Open `index.html` directly, or run a simple static web server in this folder.

## Publish on GitHub Pages

1. Create a public repository named `yuyangloveresearch` under the
   `JIANGMei-Oliver` account.
2. Upload the contents of this folder to the repository root.
3. Open **Settings > Pages** and choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.

The site will be available at:

`https://jiangmei-oliver.github.io/yuyangloveresearch/`

Repository URL:

`https://github.com/JIANGMei-Oliver/yuyangloveresearch`
